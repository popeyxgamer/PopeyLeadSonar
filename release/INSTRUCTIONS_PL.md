# 🚀 Instrukcja dla użytkownika (Wersja Windows .EXE)

Dziękujemy za pobranie PopeyLeadSonar! To narzędzie pozwoli Ci zautomatyzować proces szukania klientów (leadów) i wysyłki ofert przy użyciu AI.

## 1. Instalacja
Program nie wymaga instalacji. 
1. Pobierz plik `PopeyLeadSonar.exe`.
2. Przenieś go do osobnego folderu (np. na Pulpicie stwórz folder "PopeyLeadSonar").
3. Uruchom plik dwukrotnym kliknięciem.

## 2. Ostrzeżenie "Windows chronił Twój komputer"
Ponieważ program nie jest podpisany płatnym certyfikatem deweloperskim, Windows może wyświetlić niebieskie okno ostrzegawcze (SmartScreen).
- Kliknij przycisk **"Więcej informacji"**.
- Wybierz **"Uruchom mimo to"**.
To bezpieczne – kod programu jest otwarty i dostępny do wglądu na GitHubie.

## 3. Pierwsze kroki (Konfiguracja)
Po uruchomieniu programu:
1. Przejdź do zakładki **Ustawienia** (ikona koła zębatego po lewej).
2. W zakładce **Zaawansowane** kliknij **"➕ Dodaj konto"**.
3. Wpisz swój adres e-mail i **Hasło Aplikacji** (nie zwykłe hasło do maila!). 
   - *Porada:* Jeśli używasz Gmaila, musisz wygenerować "Hasło aplikacji" w ustawieniach bezpieczeństwa swojego konta Google.
4. Kliknij **Zapisz wszystkie ustawienia**.

## 4. Szukanie firm
1. Przejdź do zakładki **Kampania**.
2. Wpisz branże (np. "Restauracje") i miasta (np. "Warszawa").
3. Kliknij **🔍 ROZPOCZNIJ SZUKANIE**.
4. Program sam znajdzie firmy i ich adresy e-mail.

## 5. Wysyłka ofert
1. Przejdź do zakładki **Wysyłka**.
2. Wpisz treść swojej oferty. Możesz użyć symboli `{firma}` (zostanie zastąpione nazwą firmy) lub skorzystać z **Kreatora Szablonu (AI)**.
3. Kliknij **🆕 Tylko nowe**, a następnie **📤 Wyślij do wszystkich**.
