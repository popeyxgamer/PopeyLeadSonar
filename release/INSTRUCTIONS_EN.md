# 🚀 User Guide (Windows .EXE Version)

Thank you for downloading PopeyLeadSonar! This tool helps you automate the process of finding leads and sending offers using AI.

## 1. Installation
The program does not require installation.
1. Download the `PopeyLeadSonar.exe` file.
2. Move it to a separate folder (e.g., create a "PopeyLeadSonar" folder on your Desktop).
3. Run the file by double-clicking it.

## 2. "Windows protected your PC" Warning
Since the program is not signed with a paid developer certificate, Windows may show a blue warning window (SmartScreen).
- Click **"More info"**.
- Select **"Run anyway"**.
It's safe – the program code is open source and available for review on GitHub.

## 3. First Steps (Configuration)
After launching the program:
1. Go to the **Settings** tab (gear icon on the left).
2. In the **Advanced** tab, click **"➕ Add account"**.
3. Enter your email address and **App Password** (not your regular email password!).
   - *Tip:* If you use Gmail, you must generate an "App Password" in your Google account security settings.
4. Click **Save all settings**.

## 4. Searching for Companies
1. Go to the **Campaign** tab.
2. Enter industries (e.g., "Restaurants") and cities (e.g., "London").
3. Click **🔍 START SEARCH**.
4. The program will automatically find companies and their email addresses.

## 5. Sending Offers
1. Go to the **Sending** tab.
2. Enter the content of your offer. You can use `{firma}` tags (will be replaced by the company name) or use the **AI Template Wizard**.
3. Click **🆕 New only**, then **📤 Send to ALL**.
