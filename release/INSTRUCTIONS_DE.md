# 🚀 Benutzerhandbuch (Windows .EXE Version)

Vielen Dank für den Download von PopeyLeadSonar! Mit diesem Tool können Sie den Prozess der Kundengewinnung (Leads) und des Angebotsversands mithilfe von KI automatisieren.

## 1. Installation
Das Programm erfordert keine Installation.
1. Laden Sie die Datei `PopeyLeadSonar.exe` herunter.
2. Verschieben Sie sie in einen separaten Ordner (erstellen Sie z. B. auf dem Desktop einen Ordner "PopeyLeadSonar").
3. Starten Sie die Datei per Doppelklick.

## 2. Warnung "Der Computer wurde durch Windows geschützt"
Da das Programm nicht mit einem kostenpflichtigen Entwicklerzertifikat signiert ist, zeigt Windows möglicherweise ein blaues Warnfenster (SmartScreen) an.
- Klicken Sie auf **"Weitere Informationen"**.
- Wählen Sie **"Trotzdem ausführen"**.
Das ist sicher – der Programmcode ist Open Source und auf GitHub einsehbar.

## 3. Erste Schritte (Konfiguration)
Nach dem Start des Programms:
1. Gehen Sie zum Tab **Einstellungen** (Zahnrad-Symbol links).
2. Klicken Sie im Tab **Erweitert** auf **"➕ Konto hinzufügen"**.
3. Geben Sie Ihre E-Mail-Adresse und Ihr **App-Passwort** ein (nicht Ihr normales E-Mail-Passwort!).
   - *Tipp:* Wenn Sie Gmail verwenden, müssen Sie in den Sicherheitseinstellungen Ihres Google-Kontos ein "App-Passwort" generieren.
4. Klicken Sie auf **Alle Einstellungen speichern**.

## 4. Firmensuche
1. Gehen Sie zum Tab **Kampagne**.
2. Geben Sie Branchen (z. B. "Restaurants") und Städte (z. B. "Berlin") ein.
3. Klicken Sie auf **🔍 SUCHE STARTEN**.
4. Das Programm findet automatisch Firmen und deren E-Mail-Adressen.

## 5. Angebote versenden
1. Gehen Sie zum Tab **Versand**.
2. Geben Sie den Inhalt Ihres Angebots ein. Sie können `{firma}` Platzhalter verwenden (wird durch den Firmennamen ersetzt) oder den **KI-Vorlagen-Assistenten** nutzen.
3. Klicken Sie auf **🆕 Nur neue**, und dann auf **📤 An ALLE senden**.
